# 剧情建议外置 v1.6.1（基于 v1.6）

本版本在 v1.6 的基础上，只调整剧情建议追加文本：原建议后面增加一条简短提醒：

`（本轮不再附加剧情建议。）`

其余功能保持 v1.6：通用 `{{lastUserMessage}}` 宏匹配、将最新用户输入替换为「按建议剧情发展往下继续」、将真实用户输入作为 `assistant` 历史正文后的剧情建议，以及扩展设置中的启用开关和静默运行方式。

## 更新方法

**ZIP 内的插件目录仍为 `story-direction-v1-5`，可覆盖 v1.6 使用的同名插件目录。**

1. 解压 ZIP。
2. 将其中 `story-direction-v1-5` 文件夹覆盖到 `SillyTavern/data/<用户名>/extensions/story-direction-v1-5`。
3. 刷新或重启 SillyTavern。
4. 在扩展管理中确认版本为 **1.6.1**。

## 本次变化

注入上一轮 `assistant` 历史正文的格式为：

```text
建议剧情发展：<本轮真实用户输入>

（本轮不再附加剧情建议。）
```

提醒文字保留在 `assistant` 消息中，角色仍为 `assistant`。它用于提示模型后续直接续写正文；若模型仍输出剧情建议，可配合酒馆正则过滤。

## 开关

- 勾选「启用剧情建议外置」：执行 v1.6 的原有处理，并追加上述提醒。
- 取消勾选：下一次发送起跳过插件修改。
- 开关仍使用酒馆 `extensionSettings` 持久化，运行时不弹窗。

## 查看状态（可选）

浏览器开发者工具 Console 中输入 `__STORY_DIRECTION_STATUS`，可查看版本、开关状态及最近一次处理结果。
